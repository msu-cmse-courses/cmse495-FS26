# Daily Class Check-In

## Purpose

The Daily Check-In is a short reflection on participation and professionalism.

This is not traditional attendance; it is a trust-based accountability system.

## Expectations

- Submit once each class day
- Report participation honestly
- Communicate when plans changed (late arrival, reduced participation, absence)
- Use check-ins to stay accountable and improve week to week

## What This Is Not

This is not designed to police behavior. It is designed to support communication and help instructors respond early when teams need support.

## Link

Complete the form here: [Daily Check-In Form](https://msu.co1.qualtrics.com/jfe/form/SV_3yNg09psIE2ObAO)

## Important Note

Planned absences should be communicated through the planned-absence process. The Daily Check-In records what happened in class that day.
