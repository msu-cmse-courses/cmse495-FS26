# Team Directory Standards

Use your team directory as the operational home for logistics and deliverables.

## Minimum Team Folder Layout

```
Team_Folder/
  README.docx
  Team_Management_Files/
    Team_Charter.docx
    Weekly3x3/
    MeetingNotes/
    Signed_Agreements/
  Project_Deliverables/
  Data_Files/
```

Adapt naming to your project, but keep this structure easy to scan.

## Standards

- Use consistent names (no ambiguous file titles)
- Put newest/high-priority docs where people can find them quickly
- Use date prefixes when useful (YYYYMMDD)
- Keep one obvious location for recurring documents

## Required Habits

- Keep README updated as folder structure evolves
- Keep team-level documents separate from individual scratch work
- Store files where instructors can review progress without hunting
