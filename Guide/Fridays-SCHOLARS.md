# Friday: SCHOLAR Projects

SCHOLAR (Student-Crafted Hub for Open Learning and Academic Resources) is the Friday technical training track.

## Core Goal

Learn something new and teach it to the next group.

## Why This Matters

SCHOLAR work supports three course goals:

- independent learning
- collaborative software practice using git
- clear technical communication

## Typical Friday Progression

1. Review and test existing tutorials
2. File high-quality issues
3. Practice pull requests
4. Select and scope new tutorial topics
5. Develop and revise tutorials
6. Submit polished contributions

## Quality Expectations

- Work in your own words and understand what you submit
- Use clear commit messages, issues, and pull requests
- Prioritize reproducibility and clarity for future students

## Honors Option

Students pursuing the Honors option may join the SCHOLAR documentation management effort and coordinate issue triage, reviews, and repository support with instructors.
